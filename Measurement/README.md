# 電磁界強度の測定方法と測定結果

## 関連する法令と基準

LDC1612を基板パターンコイルで使う金属検出センサは、10kHz以上の高周波電流を利用するため、電波法第100条第1項第2号の「高周波利用設備（通信設備以外）」に該当し得る。ただし、同号により許可が必要となるのは総務省令で定める設備に限られ、電波法施行規則第45条では、医療用設備・工業用加熱設備・各種設備のうち高周波出力が50Wを超えるものとされている。本機の高周波出力はmWオーダーであり、設置許可は不要である。

一方、許可を要しない設備であっても、副次的に発する電波または高周波電流が無線設備の機能に継続的かつ重大な障害を与えるときは、障害除去のための措置を命じられることがある（電波法第101条により第82条第1項を準用）。

本機のコイル駆動周波数は約2MHz（LDC1612の対応範囲は1kHz〜10MHz）である。この周波数範囲で障害を与える可能性がある主な無線システムはAMラジオ放送（526.5〜1,606.5kHz）である。本機に直接適用される数値基準はないため、参考として、型式確認を受ける電磁誘導加熱式調理器の基準（電波法施行規則第46条の7：発振器から30mの距離で、526.5〜1,606.5kHzにおいて30μV/m以下）を設計目標とした。近傍界では電界は1/rより速く減衰するため、1/rで換算した「3mの距離で300μV/m（約50dBμV/m）以下」を満たせば、30mでの基準も安全側で満たすと判断できる。
